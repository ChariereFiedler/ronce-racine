# Mod ronce 0.6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The ronce mod warns on fixes without a ticket, repeated fixes and polling sleeps, signals a growing context once per threshold, reports the numbers that judge it, and is deployed current to every session.

**Architecture:** Pure functions in `mods/ronce/src/features/` (unit-tested from `tests/ronce/`), wired into `mods/ronce/hooks/register.tsx` the way `memo.ts` and `skill-hints.ts` are. Default rules are declarative entries in `src/policy/defaults.ts` with `examples`. Nothing blocks: every new behaviour warns or informs, and fails open.

**Tech Stack:** TypeScript run by `tsx`, vitest, the mod engine (`on('tool.call' | 'user.prompt' ...)`).

**Spec:** `docs/superpowers/specs/2026-11-18-mod-ronce-0.6-design.md`

## Global Constraints

- Context thresholds default to `[40, 60, 75]` (percent of the window); a threshold fires once per session.
- `fix-repeat` defaults: 3 fixes, 48 hours, mode `shadow`.
- No rule or feature may deny: new behaviours are `warn` or context text only.
- Every new feature is switchable to `null` in `.claude/ronce.json` and fails open on any read error.
- Source and commit messages in English; user-facing messages in French with correct accents. "siliceum" lowercase.
- Commit format `type(scope): description`, first line at most 72 characters, never mention Claude, AI or LLM. Ask before every commit.
- `npm test` green before any commit (see `package.json`).

## Review Focus

- `git commit --amend --no-edit`, `-F file` or a heredoc message: the message is not in the command, so `fix-needs-ticket` must stay quiet, not guess.
- `sleep 1` or `sleep 0.5` in a retry loop: quiet below 5 seconds; `sleep 30` as a wait warns.
- Context percent missing, or dropping after a compaction: no message when missing; thresholds already crossed re-arm once the percent falls below them.
- `fix-repeat` in a shallow clone, a repo with no commits or a detached HEAD: no warning and no error.
- `contextSignal` with empty, unsorted or out-of-range thresholds in `ronce.json`: defaults retained and an entry added to the policy errors, as `memo.ticketPattern` does.
